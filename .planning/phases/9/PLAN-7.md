# Phase 9: Review delivery and identity — Gap closure plan 7

## Goal

Reviewers return raw findings, the binary persists them before completion, and every fire has durable artifact identity and one configured gate meaning. Close only the seven unresolved production gaps in UAT items 151–157 against that ROADMAP goal.

## Must be true when done

- A completed execution artifact with an applicable enabled review gate produces durable review work before the next executor dispatch or completion becomes visible, including on replay.
- A definitely failed launch closes its issued attempt once without an invented host identity, allowing the saved FIRST selection to advance.
- Appended evidence cannot change the membership or claimed delivery of a completed original view.
- Ordinary risk admission returns the detector's dispatch, no-review, wait-for-evidence or ask-surfaces outcome before acquiring review material or admitting attempts.
- Minimalism requests one base reviewer inheriting the session model, independently of ordinary reviewer routing.
- Directory targets retain nested file membership and bytes, with directory nodes excluded from file evidence.
- The real MCP input boundary bounds review-return accumulation before full buffering/deserialization and preserves every accepted raw byte.

## Context

Sources are the seven `gaps` objects in verifier-findings.json and UAT items 151–157, including their recorded causes; PLAN-1 through PLAN-6 and their reports describe shipped prerequisites.
C01, D-57–D-65 and H1–H5 remain locked. AC1–AC150 remain passing; requirements above map related existing unit obligations, not new AC numbers or claims that their production compositions were already covered.
This is one sequential gaps plan: tasks share review_service.rs and supporting records. Full phase-12 execution migration, phase-10 settlement/provider work and all four MANUAL.md items remain outside these tasks.
The owner's current seven authoring rules, especially replacement rule 4, govern every new Verify below and supersede older testing instructions in CONTEXT and Plans 1–6.
