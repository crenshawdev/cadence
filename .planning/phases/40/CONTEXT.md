## Durable decisions

- D-217. search answers with rows, never bodies. One row per matching line carries the file, the line number, the line's text, the enclosing unit's name and kind, and an issued location for that unit, or a window location where no unit encloses the line; each file's issued file_reference appears once per answer. A body comes back only from read, at an issued location or by unit name under an issued file reference. This supersedes phase 31's T1 (one unit per hit) and the enclosing-unit answer of docs/architecture/read-layer.md:31-33, which stays as written until the owner's cleanup phase.
- D-218. search takes a limit that counts rows: default 50, maximum 200, a larger value refused naming the maximum. A line's text is cut at 200 characters with a marker. The cursor keeps its phase 31 meaning, re-searching from the first unserved (file, line) with no revision.
- D-219. symbol-search takes a name fragment, a scope, case_insensitive and the same limit and cursor as search, and answers each outline unit whose qualified name contains the fragment, case-sensitive unless case_insensitive is set, over units of all six grammars, with its file, kind, line range and an issued location. The outlines are built per call under the existing 5 s aggregate budget; nothing is kept in the resident between calls; files the budget did not reach are named in the answer as not searched.
- D-220. call-search takes a name, a scope and the same limit and cursor, and answers each syntactic call whose callee's last identifier equals the name: plain, path, method and generic calls, Rust macro invocations and JavaScript new, read from each grammar's call nodes. A row carries the file, the line, the line's text, the enclosing unit and an issued location. The answer states that matching is syntactic, not type-resolved. Files with no call grammar (Markdown, JSON, no grammar) are counted as not searched.
- D-221. Every search, symbol-search and call-search answer and every read slice is at or under the 65,536-byte answer bound measured on its serialized bytes. A row that would cross it goes to the next page; a slice that would cross it ends earlier with a continuation. The first row of a page is admitted against the same measure.
- D-222. The shared read contract (read/instructions.rs CONTRACT) tells every caller to locate first with search, symbol-search or call-search and to read second, by issued location or unit name, one unit at a time. It remains the one source for the server's initialize instructions and every compiled surface that carries it. The phase 31 planner-round paragraph is removed. The cadence_query description gains one sentence saying the same. The rendered byte ceilings are not raised.
- D-223. The read measurement reads a Claude Code session between two turns, main chain and every subagent, or a Codex rollout's item_completed events, and reports reads by kind with the bytes each returned: native Read whole and ranged, Grep, Glob, shell reads, and cadence_query search, symbol-search, call-search, read and document; a record it cannot classify is counted unclassified, never guessed. Before is the four phase 17 Codex runs of 2026-09-23 and one Claude episode the owner names; after is the first phase 39 runs. The report is shown to the owner unchanged and gates nothing.

## Truths

- T1. When a caller searches a pattern in a scope, the caller gets at most limit rows, one per matching line, each with its file, line number, the line's text cut at 200 characters, the enclosing unit's name and kind and an issued location for that unit (a window location where no unit encloses the line), a cursor when more remain, and no unit body.
- T2. When a caller looks up a name fragment in a scope, the caller gets each outline unit whose qualified name contains the fragment, with its file, kind, line range and an issued location, at most limit rows with a cursor, and the files the outline budget did not reach named as not searched.
- T3. When a caller asks for the calls to a name in a scope, the caller gets each syntactic call whose callee's last identifier is that name, with its file, line, the line's text, the enclosing unit and an issued location, the answer stating it is syntactic and not type-resolved, and files with no call grammar counted as not searched.
- T4. When a read-layer answer is served, the caller gets an answer at or under 65,536 bytes as serialized, for search, symbol-search, call-search and read alike, with a row that would cross the bound moved to the next page and a slice that would cross it ended with a continuation.
- T5. When the read contract is rendered where it is carried, the reader sees in every compiled surface, the server's initialize instructions and the cadence_query description: locate first with search, symbol-search or call-search, then read by issued location or unit name, with every rendered file inside its ceiling and no phase 31 measurement paragraph.
- T6. When the owner measures a host episode, the owner sees for a Claude session episode and a Codex rollout alike, native reads (whole and ranged Read, Grep, Glob, shell reads) and Cadence reads (search, symbol-search, call-search, read, document) counted by kind with the bytes each returned, and records it cannot classify counted as unclassified.

## Flagged assumptions

- A row's issued location is the existing Unit capability (read/location.rs:21-27); a line outside every unit gets the existing two-line window unit, so no new capability kind is added.
- Call sites are found by walking each grammar's tree or by a tree-sitter query over the grammars already in the binary; no new crate and no language server.
- The contract rewrite fits under every rendered ceiling because the removed phase 31 paragraph (1,145 bytes) is larger than the added text; the plan measures each rendered surface before and after.
- The Codex rollout shape read on 2026-09-23 (event_msg item_completed with item.type McpToolCall or CommandExecution) is what the measurement parses; a record without those fields is counted unclassified.
- The Claude session records measurement.rs reads today carry the main chain and subagents without a cad-planner agent; only the episode selection changes.
- A symbol-search over a directory or glob scope fits the 5 s budget; a project-wide one over 29 MB may not, and answers with the unreached files named.
