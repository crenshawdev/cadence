# Phase 4: Derivation and the internal spine - Plan 1

## Goal

Build the captured-input contract and synchronous lifecycle derivation, then make the production preparation query refuse changed or unreadable evidence before it can publish a candidate. The answer is limited to cycle, current, total, and ordered phase records; the truth table deliberately inherits existence-based completion (D-01, D-02, D-07; E01-E11).

## Must be true when done

- AC1: Production derivation returns all four lifecycle values for the artifact truth table, including complete with SUMMARY and qualifying UAT but no PLAN; removing a required skip reason changes complete to executed (D-02).
- AC2: Production parsing and derivation select the numerically first incomplete entry, preserve numeric ties in textual order, and distinguish closed/null/zero from live/null/all-complete; a checkbox never supplies completion (E02-E04).
- AC7: The production preparation query rejects injected mid-query UAT/SUMMARY changes with `inputs-changed`, and read/list/probe failures with a path-specific input error; neither returns a publishable candidate or replaces a prior memo (D-07).
- The derivation receives the same immutable capture that the later encoder will consume. No second read can silently become the key's input (D-03, D-07).
- Domain code remains synchronous and pure; the read adapter has no write method. Store ownership and durability remain the existing writer's responsibility (D-01, D-06; `crates/cadence/src/store/mod.rs:55`, `crates/cadence/src/store/writer.rs:62`).

## Context

D-01, D-02, D-03 and D-07 bind this plan. D-04 and D-05 require a separate consistency step in PLAN-2, and D-06 reserves persistence for the existing store. AC ids and D ids refer to `.planning/phases/4/CONTEXT.md`; E ids refer to `.codex-analysis/phase-4-evidence-set.md`. These decisions are settled, including SUMMARY-without-PLAN completion and refusal on observation failures. The audit's lifecycle input inventory is the boundary, not an invitation to port the full status envelope (E01-E20).

The library currently exports only `store` (`crates/cadence/src/lib.rs:1`); config/import are binary modules (`crates/cadence/src/main.rs:1-3`), and recall is included by the server (`crates/cadence/src/server.rs:17-18`). Add pure derivation to the library without moving those modules. The store's `Storage` reads owned regular files and rejects symlinks/nonregular targets (`crates/cadence/src/store/filesystem.rs:157`); that is unsuitable for SUMMARY's existence semantics. Introduce a separate read-only artifact trait, not a second store. The existing item projection and decision-record normalization remain reused without edits (`crates/cadence/src/store/items.rs:16` is the `recall_items` projection; `crates/cadence/src/store/decisions.rs:13` is `normalize`, a record normalizer and NOT a View projection; `crates/cadence/src/store/transaction.rs:129`).

All frozen citations below mean source opened with `git show v3.7.12:<path>`. No frozen path is a write lease. Names introduced in Tasks are prescribed new interfaces, not claims that they already exist. Execute PLAN-1, then PLAN-2, then PLAN-3; shared leases are intentional (D-03, D-06).

## Tasks

### Task 1: Define the captured lifecycle contract

- **Files:** crates/cadence/src/lib.rs, crates/cadence/src/derivation/mod.rs, crates/cadence/src/derivation/model.rs, crates/cadence/src/derivation/tests.rs
- **Action:** Export `derivation` and define `LifecycleStatus::{Unplanned, Planned, Executed, Complete}`, serialized only as the four lowercase words; `Cycle::{Live, Closed}`; `PhaseId` for frozen numeric identity/addressing; `PhaseRecord { id, name, plans, status, uat }`; `UatCounts { pass, fail, pending, skipped, blocked }`; and `Lifecycle { cycle, current, total, phases }`. Always retain the ordered admitted PLAN list, including empty and singleton lists; `uat` is optional counters, not a frontmatter verdict (D-01, E09-E11). Define `Observation<T>::{Present(T), Absent, Failed(InputFailure)}`, with stable error categories `PermissionDenied`, `NotDirectory`, `InvalidPath`, `SymlinkLoop`, `OtherIo`; store paths separately from categories and optional display diagnostics. Define `CapturedInputs` containing the normalized absolute root address and probe, ROADMAP read outcome/raw bytes, parsed declarations, and one `PhaseObservation` per distinct addressed path, referenced by ordered declarations. Keep checked/name/description/source-line/textual ordinal on `RoadmapPhase`, outside the lifecycle answer. Define `DerivationError` variants with stable codes for missing planning root, missing roadmap, invalid roadmap, path-specific input failure, and `inputs-changed`; reserve extension through this same error type for PLAN-2/PLAN-3. Captures can represent failures for AC3's future encoder tests, but a failure cannot validate as a successful derivation (D-03, D-07). Derive equality/serialization where needed; do not use environment, filesystem, runtime, time or synchronization in this model.
- **Verify:** `cargo test -p cadence --lib derivation::tests::contract` must run the newly named contract tests and assert exactly four accepted native lifecycle strings, rejection of a fifth spelling, distinct closed/live null-current answers, and distinct absent/empty/failed observations. Assert full round trips retain phase order, PLAN names and every optional UAT counter; zero matching tests is not verification (D-01, D-03).

### Task 2: Port the bounded ROADMAP and UAT readers

- **Files:** crates/cadence/src/derivation/mod.rs, crates/cadence/src/derivation/model.rs, crates/cadence/src/derivation/parse.rs, crates/cadence/src/derivation/tests.rs
- **Action:** Implement pure `parse_roadmap` and `parse_uat` from E02-E03 and E09-E11. For ROADMAP, remove an initial BOM and normalize CRLF, not lone CR; locate trimmed `## Phases` outside fences and stop canonical entries at the next unfenced column-zero `## ` heading. Use the exact frozen canonical phase-line grammar, lowercase `x`, optional description, stable numeric sorting, and the wider scan to document end only when no canonical entries were parsed. Missing section and zero-entry phase-shaped out-of-grammar text refuse; a real empty section without such tokens is closed; canonical entries beside malformed neighbors are retained (`cadence-core/bin/lib/planning-files.mjs:53`, `:85`, `:153`, `:1967`). Implement the frozen fence scanner, including opening-character/length and empty-info closing rules (`cadence-core/bin/lib/planning-files.mjs:1504`, `:1775`, `:1804`). Convert numeric spelling as frozen Number/String does, so `01`, `1.0`, and `1` address `phases/1`, and `1.10` shares `phases/1.1` with `1.1`; do not sort or address by original spelling (D-03, E03, E07). For UAT, split on column-zero `### `, admit only a numbered first line, bound each chunk at an unfenced `## `, and parse field lines with the frozen word-key/nonempty-value grammar and last assignment winning. Preserve the actual status/reason strings, including unknown statuses; recompute only the five known counters. Do not apply ROADMAP normalization or a new general Markdown/YAML parser to UAT. Match the frozen raw-text behavior, including numbered headings in fences where the chunk split admits them; do not silently add validation (D-02; `cadence-core/bin/lib/planning-files.mjs:1834`).
- **Verify:** `cargo test -p cadence --lib derivation::tests::parsers` must run fixtures for BOM/CRLF/lone CR, fenced fake headings and entries, section bounds, closed/no-section/out-of-grammar, valid entries with malformed neighbors, numeric ties and decimal addresses. UAT fixtures must assert that manual-note numbered prose creates no item, empty/frontmatter-only input cannot complete, duplicate fields use the last parsed value, unknown statuses increment no known counter, and field/section/fence behavior matches the opened functions (AC1, AC2; E02, E09-E11).

- **Action:** Implement synchronous pure `derive(&CapturedInputs) -> Result<Lifecycle, DerivationError>`. Validate capture availability first, then derive unplanned by default, planned from any admitted PLAN name, and override either with executed when SUMMARY exists or complete when SUMMARY exists and the nonempty UAT item set consists entirely of pass or skipped with a truthy parsed reason. Missing/empty UAT has no counters; nonempty malformed/frontmatter-only UAT has parsed zero counters and cannot complete. Preserve this distinction and unknown-item incompleteness (D-01, D-02; E07-E11). Select current from the first non-complete ordered entry; total is entry count, not maximum id or distinct path count. Closed is a classified empty roadmap, not an all-complete live list. Do not consult checkboxes when assigning lifecycle. Add the AC1 table and AC2 permutation/tie/current fixtures; have the table assert against production derivation, not a second implementation. Include a test-only mutated predicate requiring PLAN and assert the same table rejects it; keep mutation helpers inside the test module (AC1, AC2).
- **Verify:** `cargo test -p cadence --lib derivation::tests::ac1` must assert no artifacts/unplanned, PLAN-only/planned, SUMMARY/executed, qualifying SUMMARY+UAT/complete with and without PLAN, empty/nonregular PLAN/SUMMARY, malformed/empty/frontmatter-only UAT, unknown status, pass and skips with/without reason. Removing the final skip reason must yield executed; the extra-PLAN-prerequisite mutant must fail the shared table. `cargo test -p cadence --lib derivation::tests::ac2` must assert invariant current under unequal-entry permutation, stable tie order/shared addressing, closed/null/zero versus live/null/all-complete, and current moving backward when the first complete phase's UAT becomes pending. ### Task 5: Refuse candidates when observations change

- **Files:** crates/cadence/src/derivation/mod.rs, crates/cadence/src/derivation/query.rs, crates/cadence/src/derivation/tests.rs, crates/cadence/tests/derivation_inputs.rs
- **Action:** Expose the production read-side query as `prepare_query` returning `PreparedLifecycle { capture, answer }` and `recheck_query(&PreparedLifecycle, &mut ArtifactIo)` returning a `RecheckedLifecycle` only after an equivalent second capture. Offer `query` as their composition for read-side callers. Keep all constructors enforcing validation; later memo publication must consume this path and perform its final recheck immediately before return or submission to the writer (D-07). Compare only named captured observations, retaining semantic ROADMAP/UAT order and sorted PLAN names; any difference is `inputs-changed`. A second-capture observation failure is a path-specific input error, not a changed-input success.
