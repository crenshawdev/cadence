# Phase 5: The evidence record and what comes next - Plan 4

## Goal

Pausing preserves the in-flight work and the operator's resume instruction in git, with the frozen guards and a clean completion. A fresh process offers that exact sentence as the matching phase's resume action using the records and selector delivered by the preceding plans.

## Must be true when done

- AC6: A dirty-tree pause makes a guarded WIP commit containing the authorized work, commits its resume record, and reports success only with a clean tree. A clean-tree pause skips WIP but still commits its resume record.
- AC3/AC6: A protected-branch, base-integrity or applicable risk question must be answered before its guarded continuation; restart does not turn an unanswered question into permission.
- AC4/AC6: The committed pause uses the unified reasoned override contract. Saving it leaves the named resume occurrence pending, while fulfillment or supersession ends its permission and retains its history.
- AC6: After restart, a matching current phase offers the operator's byte-exact one-line sentence, including an ordinary sentence that is not a recognized command. A different-phase pause is context only, and an offer is not acceptance.
- A failed Git operation reports the remaining partial pause instead of claiming clean completion or undoing an already-made WIP commit. Store acknowledgement alone never proves a Git commit.
- All seven phase criteria have executable evidence from the four plans; the existing lifecycle and single-public-tool boundary remain intact.

## Context

Phase 5 CONTEXT D-03 through D-05 and D-09 through D-13 bind this plan; B4 at `.codex-analysis/phase-5-context-analysis.md:162` enumerates every preserved pause obligation.
PLAN-1 supplies the durable producer and gate answers, PLAN-2 the unified override/applicability reader, and PLAN-3 the internal selector; inspect their implemented interfaces before using them.
The complete frozen pause workflow is `skills/cad-pause/SKILL.md:25`; its included guard is `cadence-core/references/git-guard.md:8`, `:22`, `:121`. Store transactions do not perform Git operations (`crates/cadence/src/store/writer.rs:291`).
Run last in the sequential chain. Phase 6 owns public dispatch; Phase 7 owns the general shell hook and risk-gate rollout. This plan preserves the pause-local obligations locked by D-04.
