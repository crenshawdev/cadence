# Design decisions and lineage

Cadence grew from [GSD](https://github.com/open-gsd/gsd-core) and its discuss, plan, execute and verify loop. I kept that core idea and narrowed the tool around the way I work as a single developer.

The history matters because some of the current boundaries came from trying a broader approach and paying for it. It belongs here for readers who want to understand those choices, without making everyone read it before using the tool.
